# Happy Birthday Hawra 🎀

## Add photos
Put 4 photos in `photos/` named `1.jpg` … `4.jpg` (.png, .jpeg and .webp also work).
Missing photos show a cute 🎀 placeholder, so the site works either way.

## Add a song (optional)
Put an mp3 at `music/song.mp3`. It starts when she taps "open it", and a 🎵 button appears to pause it.

## Deploy on GitHub Pages
1. Create a new public repo on github.com (e.g. `hawra-birthday`).
2. Click **Add file → Upload files** and drag in everything *inside* this folder
   (`index.html`, `style.css`, `script.js`, `.nojekyll`, `photos/`, `music/`).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-username>.github.io/hawra-birthday/`.
